# Atribución de medios de ejercicios

comunitaria de [wger.de](https://wger.de) y se usa bajo las licencias Creative Commons que
indica cada fila (CC-BY-SA 3.0, CC-BY-SA 4.0 o CC0). La app muestra la atribución junto a
cada imagen tal como exige la licencia; este documento es el registro completo.

- Ejercicios con foto: **73** (empaquetadas en `assets/exercises/`).
- Ejercicios con vídeo enlazado: **26** (no se empaquetan, se abren desde wger.de).
- Generado el 2026-09-24 desde la API pública `https://wger.de/api/v2/` (endpoint `exerciseinfo`).
- Las fotos se redimensionaron a un máximo de 1024 px y algunas se recomprimieron a JPEG para reducir el peso del paquete; no se han recortado ni alterado de otro modo.
